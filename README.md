# What's in my bag?

밝은 사탕 색(주황·분홍·하늘)과 둥근 글씨(Jua, Fredoka)로 꾸민 초등 3학년용 화면입니다.

초등학교 3학년 영어 수업용 웹 앱입니다. `index.html` 하나로 동작하며 Chrome 또는 Edge 에서 열면 됩니다.

표현: Do you have a(n) ___? / Yes, I do. I have a(n) ___. / No, I don't. I don't have a(n) ___.

## 세 단계, 가방 하나 (최대 5개)
1. **단어** — 물건 20개. 그림을 누르면 항상 단어 발음이 나오고 대화문이 바뀝니다. "가방에 넣기" 버튼이나 아래 가방으로 끌어 넣기로 담습니다. 5개가 차면 나머지 버튼이 잠깁니다.
2. **내 가방** — 앞판이 투명한 젤리 가방입니다. 넣은 물건이 투명 창 안에 바닥부터 쌓여 통째로 보이고, 물건을 누르면 단어를 들려줍니다. 옆의 **꾸미기** 카드로 가방을 꾸밉니다.
   - 색깔: 노랑, 분홍, 초록, 파랑, 보라
   - 동물: 곰, 고양이, 토끼, 강아지 (귀와 얼굴이 바뀜)
   - 안감: 물방울, 별, 하트, 줄무늬, 체크, 없음
   - 장식: 지퍼에 다는 하트, 별, 딸기, 클로버, 왕관
   - 스티커: 14가지 중 8개까지 붙이기. 끌어서 옮기고, 누르면 뗄 수 있음
   - 이름표: 이름을 쓰면 가방에 이름표가 달림
   꾸민 가방은 브라우저에 저장되어 다음에 열어도 그대로입니다.
3. **말하기** — 가방에 있는 물건을 골라 질문 / Yes 대답 / No 대답 세 문장을 듣고 🎤 따라 말하면 정확도(%)와 단어별 표시를 보여줍니다. 세 문장 모두 80% 이상이면 물건에 ✓ 가 붙습니다.

가방 내용은 브라우저에 저장되어 새로고침해도 유지됩니다.

## 그림
- 스티커와 동물 얼굴 고르기 그림: Fluent Emoji Flat (Microsoft, MIT).
- 펜, 연필, 자, 공책, 크레용, 가위, 책, 스티커, 키링, 우산, 도시락, 곰 인형, 사과, 붓: [Fluent Emoji](https://github.com/microsoft/fluentui-emoji) (Microsoft, MIT). SVG를 파일 안에 포함했으므로 인터넷 없이도 표시됩니다.
- 딱풀, 지우개, 필통, 물병, 키캡, 슬라임과 곰돌이 백팩: 공개 아이콘 세트에 없어 같은 질감으로 직접 그렸습니다.

## 참고

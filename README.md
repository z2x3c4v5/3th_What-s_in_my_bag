# What's in my bag?

초등학교 3학년 영어 수업용 웹 앱입니다. `index.html` 하나로 동작하며, Chrome 또는 Edge 에서 바로 열면 됩니다.

## 표현
- Do you have a(n) ____?
- Yes, I do. I have a(n) ____.
- No, I don't. I don't have a(n) ____.

## 세 탭은 하나의 가방을 공유합니다

### 1. 단어 배우기
- 학용품 단어 카드 18개 (교과서 단어 pen, glue stick, ruler, eraser, notebook, crayon 포함)
- 카드를 누르면 발음을 들려주고, 위의 문장 패턴에 단어가 들어갑니다. a / an 표시
- 카드를 오른쪽 아래 **미니 가방으로 끌어다 놓으면** 가방에 들어갑니다. 카드의 "+ 가방에 넣기" 버튼으로도 넣을 수 있습니다
- 듣고 고르기: 소리를 듣고 맞는 카드를 고르는 미니 퀴즈

### 2. 문장 연습하기
- 가방에 넣은 단어가 자동으로 연습 목록이 됩니다
- 단어마다 세 문장(질문 / Yes 대답 / No 대답)을 🔊 로 듣고, 🎤 를 누른 뒤 따라 말하면 **정확도(%)** 를 보여줍니다
- 맞게 말한 단어는 초록색, 빠지거나 틀린 단어는 빨간색으로 표시됩니다. 80% 이상이면 별을 줍니다
- 음성 인식은 브라우저의 Web Speech API 를 씁니다. Chrome / Edge 에서 마이크 권한을 허용해야 하며, 인터넷 연결이 필요합니다

### 3. 내 가방
- 1번에서 넣은 물건이 백팩 그림 안에 들어 있습니다. 누르면 꺼냅니다
- "I have a pen, an eraser and slime." 처럼 가방 전체 문장을 읽어 줍니다
- 친구가 물어봐요: "Do you have a(n) ___?" 질문에 가방을 보고 Yes, I do. / No, I don't. 로 대답하는 퀴즈

가방 내용은 브라우저에 저장되어 새로고침해도 유지됩니다.

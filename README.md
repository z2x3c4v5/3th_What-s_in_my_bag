# What's in my bag?

초등학교 3학년 영어 수업용 웹 앱입니다. `index.html` 하나로 동작하며 Chrome 또는 Edge 에서 열면 됩니다.

표현: Do you have a(n) ___? / Yes, I do. I have a(n) ___. / No, I don't. I don't have a(n) ___.

## 세 단계, 가방 하나
1. **단어** — 학용품 15개. 누르면 발음과 대화문이 나오고, 아래 가방으로 끌어 넣거나 + 를 누르면 가방에 들어갑니다.
2. **말하기** — 가방에 넣은 물건으로 한 번에 한 문장씩 연습합니다. 듣기 → 🎤 따라 말하기 → 정확도(%)와 단어별 표시. 가방에 없는 물건 하나로 No 대답도 연습합니다.
3. **내 가방** — 백팩 그림 안에 물건이 들어 있습니다. 누르면 꺼냅니다. 친구의 질문에 Yes, I do. / No, I don't. 로 답합니다.

가방 내용은 브라우저에 저장되어 새로고침해도 유지됩니다.

## 참고
- 음성은 브라우저 내장 TTS, 따라 말하기는 Web Speech API 음성 인식을 씁니다. Chrome / Edge, 마이크 허용, 인터넷 연결이 필요합니다.
- GitHub 저장소 Settings → Pages 를 켜면 학생들이 링크로 접속할 수 있습니다.

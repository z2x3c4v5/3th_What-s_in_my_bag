# What's in my bag?

초등학교 3학년 영어 수업용 웹 앱입니다. `index.html` 하나로 동작하며 Chrome 또는 Edge 에서 열면 됩니다.

표현: Do you have a(n) ___? / Yes, I do. I have a(n) ___. / No, I don't. I don't have a(n) ___.

## 세 단계, 가방 하나 (최대 5개)
1. **단어** — 학용품 15개. 누르면 발음과 대화문이 나오고, "가방에 넣기" 버튼이나 아래 가방으로 끌어 넣기로 담습니다. 5개가 차면 나머지 버튼이 잠깁니다.
2. **내 가방** — 백팩 그림의 5칸에 물건이 들어 있습니다. 누르면 꺼냅니다. 가방 전체 문장 읽기와 친구의 질문(Yes, I do. / No, I don't.)이 있습니다.
3. **말하기** — 가방에 있는 물건을 골라 질문 / Yes 대답 / No 대답 세 문장을 듣고 🎤 따라 말하면 정확도(%)와 단어별 표시를 보여줍니다. 세 문장 모두 80% 이상이면 물건에 ✓ 가 붙습니다.

가방 내용은 브라우저에 저장되어 새로고침해도 유지됩니다.

## 그림
- 펜, 연필, 자, 공책, 크레용, 가위, 책, 스티커, 키링, 가방 아이콘: [Fluent Emoji](https://github.com/microsoft/fluentui-emoji) (Microsoft, MIT). SVG를 파일 안에 포함했으므로 인터넷 없이도 표시됩니다.
- 딱풀, 지우개, 필통, 물병, 키캡, 슬라임: 공개 아이콘 세트에 없어 같은 질감으로 직접 그렸습니다.

## 참고
- 음성은 브라우저 내장 TTS, 따라 말하기는 Web Speech API 음성 인식을 씁니다. Chrome / Edge, 마이크 허용, 인터넷 연결이 필요합니다.
- GitHub 저장소 Settings → Pages 를 켜면 학생들이 링크로 접속할 수 있습니다.
